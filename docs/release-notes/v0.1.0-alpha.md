# v0.1.0-alpha — first public build

Port PC native untuk *The Warriors* (Xbox, 2005), hasil recompilasi statis dari `default.xbe`. Rilis ini berisi alat
dan runtime saja; data game tetap milik pemain.

## Isi unduhan

```
TheWarriors-port-v0.1.0-alpha.zip   (59 MB)
  TheWarriorsLauncher.exe
  TheWarriors.exe
  msvcp140.dll, vcruntime140.dll, vcruntime140_1.dll
  compiler/            clang, lld-link, xbe_recomp, XDK layout
  assets/              kosong, berisi instruksi
  README.md, README.id.md, THIRD_PARTY.md, LICENSE
```

Tidak ada `TheWarriors.dll` dan tidak ada data game. Kode game dibangun di PC pemain dari `default.xbe` miliknya
pada peluncuran pertama (1,5–4 menit, sekali per rilis).

## Cara pakai

1. Ekstrak ke folder yang bisa ditulis, jangan di `C:\Program Files`.
2. Taruh disc Xbox NTSC/USA milikmu di `assets/` sebagai `.iso`, atau hasil ekstrak lengkap
   (`default.xbe` + WAD + `audio/` + `bik/`).
3. Jalankan `TheWarriorsLauncher.exe`, arahkan tab **Folder game** bila perlu, lalu **MAINKAN**.

Detail dan troubleshooting: `README.md` di dalam zip, atau
<https://github.com/irsyadkgr678/TheWarriors-XBE#playing-a-release-build>.

## Yang berfungsi

- boot ke menu dan masuk gameplay
- renderer Direct3D 12
- audio XACT: dialog, musik, efek 3D
- mouse dan keyboard, termasuk mouse-look, prompt tombol, panel F10
- gamepad lewat SDL3 dengan rumble

## Diketahui belum ada

- MSAA
- output 720p (masih 480p)
- System Link / online
- misi lanjut belum diuji tuntas; alpha ini baru melewati misi-misi awal

## Syarat minimum

- Windows 10/11 64-bit
- CPU x86-64 dengan SSE4.2 dan POPCNT (Intel Nehalem/Core generasi 1 ke atas, AMD FX ke atas)
- GPU Direct3D 12 feature level 11_0 (GTX 600+, HD 7000+, Intel HD 4200+)
- 2 GB RAM, sekitar 7 GB untuk data game

## Data game

Hanya rilis Xbox **NTSC/USA retail** dengan `default.xbe` SHA-1 `fe246a74501cd10d2ce89ca5dbda5080d2b2edcc`. Versi
PAL/EUR dan versi PS2/PSP tidak didukung build ini.
