# v0.1.0-alpha — first public build

A native PC build of *The Warriors* (Xbox, 2005), produced by static recompilation of `default.xbe`. This release
contains the runtime and tooling only; the game data stays with the player.

## What is in the archive

```
TheWarriors-port-v0.1.0-alpha.zip   (59 MB)
  TheWarriorsLauncher.exe
  TheWarriors.exe
  msvcp140.dll, vcruntime140.dll, vcruntime140_1.dll
  compiler/            clang, lld-link, xbe_recomp, XDK layouts
  assets/              empty, with instructions
  README.md, README.id.md, THIRD_PARTY.md, LICENSE
```

There is no `TheWarriors.dll` and no game data. The game's code is compiled on the player's machine from their own
`default.xbe` on first launch (1.5–4 minutes, once per release).

## How to run it

1. Extract the archive to a folder you can write to. Not `C:\Program Files`.
2. Put your Xbox NTSC/USA disc in `assets/` as a single `.iso`, or as a full extraction (`default.xbe` plus WADs,
   `audio/`, `bik/`).
3. Run `TheWarriorsLauncher.exe`, use the **Game files** tab if the ISO lives elsewhere, then press **Play**.

Full guide and troubleshooting: [tester guide](https://github.com/irsyadkgr678/TheWarriors-XBE/blob/main/docs/INSTALL-FOR-TESTERS.md).

## What works

- boot to the main menu and into gameplay
- Direct3D 12 renderer
- XACT audio: dialogue, music, 3D positional effects
- keyboard and mouse, including mouse-look, button prompts and the F10 panel
- gamepads through SDL3, with rumble

## Known limitations

- no MSAA
- 720p output not implemented; the game runs at 480p
- no System Link or online play
- later missions are untested; this alpha covers the opening missions

## Requirements

- Windows 10/11 64-bit
- x86-64 CPU with SSE4.2 and POPCNT (Intel Nehalem/Core 1st gen or newer, AMD FX or newer)
- GPU with Direct3D 12 feature level 11_0 (GTX 600+, HD 7000+, Intel HD 4200+)
- 2 GB RAM, about 7 GB for the game data

## Game data

Only the Xbox **NTSC/USA retail** release is supported, with `default.xbe` SHA-1
`fe246a74501cd10d2ce89ca5dbda5080d2b2edcc`. PAL/EUR discs and the PS2/PSP versions do not work with this build.
